# Math Practice App

A browser-based arithmetic practice app for children ages 7–12. Students answer multiple-choice questions, flip cards to check answers, and review similar questions from earlier mistakes. Progress is stored in the browser; no account is required.

This repository currently includes the Phase 1 project setup: React, Vite, TypeScript, linting, formatting, and testing.

## Requirements

- Node.js 20 or later
- npm

## Installation

```bash
npm install
```

## Commands

Start the development server:

```bash
npm run dev
```

Run the test suite once:

```bash
npm run test:run
```

Run tests in watch mode:

```bash
npm test
```

Lint the project:

```bash
npm run lint
```

Format source files:

```bash
npm run format
```

Check formatting without writing changes:

```bash
npm run format:check
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
